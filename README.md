В данном проекте реализуется рекомендательная система для улучшения маркетинга и помощи сотрудникам в предложении персонализированных услуг клиентам. Реализуются варианты рекомендательных технологий на основе банковских аккаунтов клиентов банка. В зависимости от продуктов, которыми пользуется клиент выдаются рекомендации. В проекте так же реализуется оповещение клиента о наличии рекламных предложений через Telegram-бот посредством сети Internet.

В проекте используется следующий стек технологий:

язык программирования Java версии 17;

фреймворк Springboot 4.1.1;

версия сборки Gradle 9.7.1;

веб часть Spring Web MVC (spring-boot-starter-webmvc);

сессии JDBC Sessions (spring-boot-starter-session-jdbc);

база данных H2 (встроенная, in-memory);

тестирование JUnit 5 (Junit Platform).

внешние интеграции: Telegram Bots API (StarBankBot)

Это стандартное Spring Boot веб-приложение с управлением сессиями через JDBC и встроенной базой данных H2.
