# Implementation Plan: Recommendation Service

## Overview
Build a Spring Boot recommendation service with REST API `GET /recommendation/{user_id}` that analyzes user transactions and recommends bank products based on rule-based criteria.

## Architecture
```
Controller → Service → Repository (JdbcTemplate)
                ↓
         RuleSet implementations (interface-based)
```

## Step-by-Step Implementation

### Step 1: Database Setup
**Files:**
- `src/main/resources/schema.sql` - Create PRODUCTS, USERS, TRANSACTIONS tables
- `src/main/resources/data.sql` - Insert sample data (PRODUCTS, USERS, TRANSACTIONS)
- `src/main/resources/application.properties` - Configure H2 database

**Schema:**
```sql
PRODUCTS: ID (UUID PK), TYPE (VARCHAR: DEBIT/CREDIT/SAVING/INVEST), NAME (VARCHAR)
USERS: ID (UUID PK), USERNAME (VARCHAR), FIRST_NAME (VARCHAR), LAST_NAME (VARCHAR)
TRANSACTIONS: ID (UUID PK), PRODUCT_ID (UUID FK), USER_ID (UUID FK), TYPE (VARCHAR: DEPOSIT/WITHDRAW), AMOUNT (DECIMAL)
```

**Sample data:** At least 2-3 users with varied transaction patterns to test both rules.

### Step 2: DTO Layer
**File:** `com.example.bank_start.dto.RecommendationDTO`
```java
public record RecommendationDTO(
    String userId,
    List<RecommendationItem> recommendations
) {}

public record RecommendationItem(
    String name,
    String id,
    String text
) {}
```

### Step 3: Rule Interface
**File:** `com.example.bank_start.rule.RecommendationRuleSet`
```java
public interface RecommendationRuleSet {
    Optional<Recommendation> evaluate(UUID userId);
    String getRuleName();
}
```

### Step 4: Rule Implementations
**Files:**
- `com.example.bank_start.rule.Invest500Rule`
- `com.example.bank_start.rule.SimpleCreditRule`

**Rule 1 - Invest 500 (ID: 147f6a0f-3b91-413b-ab99-87f081d60d5a):**
- User has DEBIT product
- User has NO INVEST product
- SAVING product deposits > 1000

**Rule 2 - Простой кредит (ID: ab138afb-f3ba-4a93-b74f-0fcee86d447f):**
- User has NO CREDIT product
- DEBIT deposits > DEBIT withdrawals
- DEBIT withdrawals > 100,000

Each rule uses parameterized JdbcTemplate queries.

### Step 5: Repository Layer
**File:** `com.example.bank_start.repository.TransactionRepository`

Methods using JdbcTemplate:
- `hasProductType(UUID userId, String type)` - boolean
- `hasNoProductType(UUID userId, String type)` - boolean
- `getSumByProductTypeAndTransactionType(UUID userId, String productType, String transactionType)` - BigDecimal
- `getUserProducts(UUID userId)` - List of products

### Step 6: Service Layer
**File:** `com.example.bank_start.service.RecommendationService`

Injects all `RecommendationRuleSet` implementations via `@Autowired List<RecommendationRuleSet>`.
- `evaluateRecommendations(UUID userId)` - iterates through rules, collects matches

### Step 7: Controller Layer
**File:** `com.example.bank_start.controller.RecommendationController`

```java
@GetMapping("/recommendation/{user_id}")
public ResponseEntity<RecommendationDTO> getRecommendations(@PathVariable("user_id") UUID userId) {
    // Returns 200 with empty list if no recommendations
}
```

### Step 8: Unit Tests
**Files:**
- `src/test/java/com/example/bank_start/service/RecommendationServiceTest.java`

curl http://localhost:8080/recommendation/{user_id}

## Verification
1. Build passes: `./gradlew build`
2. Application starts without errors
3. Test with known user IDs:
   - User with debit + saving deposits > 1000 → gets "Invest 500"
   - User with debit withdrawals > 100k, deposits > withdrawals, no credit → gets "Простой кредит"
   - User with no matches → returns `{"user_id": "...", "recommendations": []}`
4. Invalid UUID → 400 Bad Request
